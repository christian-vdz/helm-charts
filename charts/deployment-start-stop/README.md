# deployment-start-stop

![Version: 0.2.0](https://img.shields.io/badge/Version-0.2.0-informational?style=flat-square)

A Helm chart designed to scale deployments up or down, in order to start or stop them.

## Install

`helm install my-deployment-start-stop oci://ghcr.io/christian-vdz/helm-charts/deployment-start-stop --version 0.2.0`
