A Helm chart for Dreeve, a self-hosted web application that provides insights and analytics for Strava activities.

## Source repository

https://github.com/dreeveapp/dreeve

## Chart features

- Create Deployment with Persistent Volume
- Create GatewayAPI HTTPRoute ou Ingress
- Override app [default configuration](https://raw.githubusercontent.com/dreeveapp/dreeve/refs/heads/master/docs/configuration/config-yaml-example.md)

> [!WARNING]
> * **Backup before updates**: Always backup your persistent volumes before upgrading.
> * **Stay up-to-date**: Make sure you're running the latest version for the best experience.
> * **Check the release notes**: Always check the release notes to verify if there are any breaking changes.
